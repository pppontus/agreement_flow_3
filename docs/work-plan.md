# Aktuell arbetslista

Beslut 2026-09-07: privatflöde och gemensam grund. Datum-, kontakt- och fakturautkast återställs vid omladdning. Efter den lokala verifieringen har användaren beställt publicering till GitHub och befintlig GitHub Pages.

## Genomförd etapp

- Gemensamma navigeringsregler, giltiga steg och återupptagning.
- Validerad lagring version 9 med migration från version 7/8.
- Bevarade formulärutkast och fungerande bakåtnavigering.
- Avbrytbar identifiering, fel/omförsök och kvittens efter slutförd simulerad signering.
- Projektdokumentation, Node 24, enhets- och webbläsartester samt CI före publicering.

Verifiering: [lokal kontrollrapport](verification.md).

## Nästa etapp

- Separat UX-genomgång av privatflödet med användaren: förståelse, stegordning, copy och visuell tydlighet.
- Separata beslut och implementation för företagsflödets fortsättning.

## Historiska underlag

Äldre rotfiler om MVP, prisinformation och företag bevaras för spårbarhet. Deras checkboxar är historiska ögonblicksbilder. Aktuell kod och körda tester avgör implementerat beteende; denna arbetslista avgör nuvarande etapp. Oavgjorda produkt- och juridikfrågor ska inte lösas genom att tyst behandla ett äldre förslag som ett aktuellt beslut.
